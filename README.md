# MizuOpti

![MizuOpti project artwork](modrinth-cover.png)

Fabric-мод для Minecraft 26.2, который уменьшает нагрузку серверного AI мобов вдали от игроков.

Когда рядом с мобом нет игроков, его `serverAiStep` выполняется один раз за заданное число тиков. Обычный тик сущности и физика не отключаются. Игроки, снаряды и другие сущности вне класса `Mob` не затрагиваются; мобы в заданном радиусе работают без пропусков AI.

## Настройки

После первого запуска сервера создаётся `config/mizuopti.properties`:

```properties
player-range=32
ai-interval=4
```

`player-range` задаёт радиус, в котором AI работает каждый тик (0–256 блоков). `ai-interval` задаёт частоту AI за пределами радиуса (1–20 тиков; значение 1 отключает пропуск AI). Изменения применяются при следующем запуске сервера.

Для мультиплеера мод устанавливается на сервер. В одиночной игре оптимизация работает во встроенном сервере.

## Сборка

Требуется JDK 25 и Gradle. Запустите из корня проекта:

```powershell
gradle build
```

Готовый мод появится в `build/libs/`.
